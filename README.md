# Học Cùng AI

Website hướng dẫn sinh viên dùng AI và AI Agent hiệu quả, có trách nhiệm (bài tập Lab 8, Phần B).

## Cấu trúc thư mục
- `css/` – `site.css` dùng chung cho mọi trang
- `js/` – `site.js` (menu, trình phát tùy biến, nút «Xem thêm»)
- `img/` – ảnh (WebP + JPEG dự phòng, SVG)
- `video/` – MP4, WebM, WebVTT, poster
- `audio/` – MP3, OGG
- `media/` – `README.md` (nguồn, giấy phép) và `media.json`

## Chạy thử
`python3 -m http.server 8000` rồi mở http://localhost:8000
